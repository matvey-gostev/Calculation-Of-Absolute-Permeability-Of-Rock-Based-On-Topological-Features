# Telegram-бот для анализа проницаемости горных пород

Проект превращает ноутбук `main_v12.ipynb` в рабочий Telegram-бот:

- принимает пользовательский 3D-массив породы (`.npy` / `.npz`, опционально `.mat`);
- валидирует размерность, пропуски и численные значения;
- заполняет пропуски ближайшей интерполяцией и ресемплит куб к размеру модели;
- позволяет выбрать `real`, `synthetic` или `mixed` как auto real/synth;
- строит визуализацию порового пространства, persistent diagram и проектные иллюстрации фильтраций;
- дает 5 готовых пресетов пород.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` или окружении задайте токен:

```bash
export TELEGRAM_BOT_TOKEN="123456:telegram-token"
python -m rockbot.bot
```

Для локальной проверки без Telegram:

```bash
python -m rockbot.bot --self-test --target-shape 64,64,64
```

Минимальный бот работает без тяжелых TDA-пакетов. Для настоящего инференса по persistent diagrams установите дополнительно:

```bash
pip install -r requirements-topology.txt
```

## Команды бота

- `/start` - краткое меню;
- `/models` - выбор модели;
- `/model real`, `/model synthetic`, `/model mixed` - быстрый выбор модели;
- `/presets` - пять готовых камней;
- отправьте `.npy` или `.npz` документом - бот обработает куб и вернет результат с картинками.

Ожидаемая кодировка данных: `1` - поры, `0` - матрица породы. Если вход не бинарный, бот сам выберет порог и напишет это в отчете предобработки.
